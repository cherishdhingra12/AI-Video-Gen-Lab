# The दादी brief, written twice — your proof

The same brief that produced the shipped `dadi-ki-bucket-list`, run through the new writer and the
new critic. **No video credit was spent** — this is the whole point: the writing is judged before
anything is filmed.

| file | what it is |
|---|---|
| `old_script.md` | the script that actually shipped (the lover of this reel, untouched) |
| `new_script.md` | what the same brief produces now |
| `critique_of_old.json` | the new critic reading the SHIPPED script — 8 findings |
| `critique_of_new.json` | the findings behind the new script (draft → critic → rewrite, 2 passes) |
| `critique_of_final.json` | the critic reading the FINISHED new script — what is still wrong with it |

## What the critic caught in the shipped script (8 findings)

- `[hook]` the opener card is a contents page — it announces a list
- `[shape]` beats 2–5 are four interchangeable items: pizza, dance, flight, selfie — no cause, no turn
- `[concrete]` nothing specific survives: generic pizza, generic flight, "cartoon-style"
- `[dialogue]` "पहला आइटम", "मेरे दिल को धड़काता है" — written Hindi, not a grandmother's speech
- `[budget]` 18 words in a 7-second clip (the table allows ~15)
- `[moral]` the card is a platitude plus a question — a question is a CTA wearing a moral's clothes
- `[sameness]` the architecture repeats an already-shipped reel
- `[length]` silent cards push it past the 30–35s the brief asks for

Every one of these is a defect you already suspected about that reel. That is the measure of the
new critic: it finds the real thing, and it quotes the line it is objecting to.

## What the new script does that the old one didn't

- **A turn.** The list is not hers: the notebook cover reads **"विक्रम की लिस्ट — 1984"** — her late
  husband's. The last tick lands the twist instead of a fifth cheerful item.
- **One concrete object that recurs in every clip** — the red notebook with the gold thread, which
  ends up as her mangalsutra. (`old_script.md` has no such object.)
- **The dialogue speaks.** "पहली उड़ान, पहला बादल" — and the words the brief mandated are used
  as the brief wrote them.
- **Word counts are counted**, per line, against each beat's seconds.

## What is STILL wrong with it — read this before you judge

The critic's second read leaves 7 findings, and they split in two:

- **The brief's own choices.** It mandates the hook card, the four items and the moral text, so
  "it is a listicle" and "the architecture repeats" are findings about the BRIEF, not the writing.
  No writer can make a brief that says *four happy items, end on her grin* into a story with a turn
  unless it is allowed to change the items.
- **Two real ones.** Beat 5 packs 20 words into 7 seconds (too fast to say), and the twist makes the
  mandated moral — "सपनों की कोई उम्र नहीं होती" — about *Vikram's* dreams, not hers, so the story
  does not quite earn the line the brief asked for.

## One rule this proof forced

STORY.md now says **the IDEA is the client**: when a brief names its own hook text or moral, the
writer uses those words and builds the story that earns them. The first run of the critic spent both
its rewrites fighting a hook card the brief had demanded — correct about the sentence, useless to
the reel. The wording is in STORY.md §1 and §5; delete it if you disagree with it.
